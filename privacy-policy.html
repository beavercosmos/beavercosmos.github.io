Privacy Policy – Beaver Studio Uploader

Last updated: 13 November 2026

Beaver Studio ("we") operates the Beaver Studio Uploader, an internal tool that publishes videos produced by Beaver Studio to Beaver Studio's own YouTube channel (@beaverstudioai). This policy explains what data the tool uses.

YouTube API Services

The Beaver Studio Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. YouTube is a Google service; Google's handling of data is described in the Google Privacy Policy.

What data we access

  • With the owner's permission (Google OAuth), the tool uploads videos and their title, description, tags, language and thumbnail to the authorised YouTube channel, and reads that channel's basic details and list of its own uploads.
  • We do not access viewers' data, comments, or any other user's channel.

How data is stored and shared

  • The OAuth access token is stored only on Beaver Studio's own computer, to let the tool upload without asking to log in each time.
  • We do not sell, share, or transfer any data to third parties. No YouTube data is stored by us beyond the token above.
  • We do not use cookies or tracking.

Revoking access and deleting data

Access can be revoked at any time through the Google security settings page. When access is revoked, or on request, the stored token is deleted within 7 days. To request deletion, email cosmosbeaver@gmail.com.
